# ひなた日本語ラボ

基础日语学习站。以《大家的日语》第 1–25 课的语法顺序为骨架，配套五十音复习、课文朗读 / 跟读、动漫场景迁移和综合测验。

## 打开方式

```powershell
cd C:\Users\wangxf11\lobsterai\project\jp-lab
python -m http.server 4180 --bind 127.0.0.1
```

然后访问 <http://127.0.0.1:4180/>。也可以在 LobsterAI 的 Portals 面板直接打开「ひなた日本語ラボ」。

## 功能

1. **五十音**：平假名 / 片假名 × 清音 / 浊音·半浊音 / 拗音，按行分组，点击发音；假名 ↔ 罗马音随机 10 题测验，答错自动进错题本。
2. **课文**：25 课，每课含学习目标、文型（带使用条件说明）、例文 6 句、会话 6 句、单词表 10–16 个。
3. **朗读**：逐句朗读、慢速 0.7×、顺序朗读、跟读模式（句后留白）、可隐藏中文盲听、对话角色遮挡练习。
4. **动漫场景**：14 个常见动漫场景的台词，标注对应课次、语法点、语气和「敬体 → 简体」转换。
5. **复习测验**：从已完成课程中抽单词做中文 → 日语四选一，记录正确率与历史成绩。
6. **进度**：全部保存在浏览器 `localStorage`，key 为 `jp-lab-progress-v1`。

## 语音说明

朗读使用浏览器内置的 Web Speech API（`speechSynthesis`），首选 `ja-JP` 语音。

1. Windows：设置 → 时间和语言 → 语言和区域 → 添加日语 → 语言选项 → 下载「语音包」。
2. 推荐 Chrome / Edge。若右上角显示「未检测到日语语音」，说明系统没有日语语音包。
3. 语速由页面内的「语速」选择器控制，慢速档为 0.7×。

## 内容边界

语法框架与课次对应《大家的日语》第 1–25 课，但例文、会话、单词练习句均为本站自编，未复制教材原文，避免版权问题。若需配合实体教材使用，可把课文原句替换进 `lessons-*.js` 的 `reibun` / `kaiwa` 字段（仅限个人学习用途）。

## 扩展数据

新增一课，在 `lessons-2.js` 末尾追加：

```js
{
  id: 26,
  title: "标题（日文）",
  sub: "中文副标题",
  goal: "本课目标，一两句话",
  bunkei: [{ jp: "句型", cn: "中文", note: "使用条件" }],
  reibun: [{ jp: "例文", cn: "中文" }],
  kaiwa: [{ sp: "A", jp: "台词", cn: "中文" }],
  words: [{ jp: "单词", kana: "假名", cn: "中文", type: "名" }]
}
```

`app.js` 会自动合并 `LESSONS_A` 与 `LESSONS_B`，课次列表、进度统计、测验题库同步更新。
